# Agent working friction, November 2026

This is the friction lanes hit in their working conditions: briefs, docs,
instructions, tools and the environment. Friction with Stitchwort itself
goes on the board as tickets instead. Each lane's report ends with a
"Working friction" section, and the orchestrator adds it here when the
lane is merged (D3673, Matt, 17 Nov 2026).

Once a week, a paper lane reads the entries, groups recurring patterns, and
proposes changes to `CLAUDE.md`, `docs/workflow.md`, the proving guide, the
lane agent definitions (`.claude/agents/`) or the brief templates. Matt
approves them.

Each entry gives:
- the date, ticket, model, and the task in one sentence;
- each item: what happened, roughly what it cost, and what would have helped.
